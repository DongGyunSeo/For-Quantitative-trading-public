## 🧪 Iteration 023: 청산 히트맵 피처 설계 (Entry용)
------------------------------------------------------------
### 문제
- 모든 피처가 가격 구조 기반 → 레버리지 포지션이라는 독립 정보축 필요
- 청산 히트맵(CoinGlass류)을 OHLCV로 근사하여 유동성 풀 정량화
### 해결
- Entry model에 추가 결정 (진입 시점 1회 계산, TP/exit는 매봉 재계산이라 무거움)
- liquidation_heatmap_features.py 신규 모듈:
  - 14일 lookback (4032봉), 레버리지 10/25/50/100x, 1/L 가중
  - 가격축 240 bin에 청산가 누적
  - 거래량 기반 소멸: 평균 1배 통과 = 0.5 소멸, 곱연산 누적, 0~1 capping
  - 미래참조 차단: 진입 봉 이전만 슬라이스
- 피처 2개: sweep_liq_consumed, liq_imbalance_hm
### 인사이트
- 소멸 처리 완전제거 대신 거래량 기반 채택 (고거래량 통과 = 더 소멸)
- log 공간 합연산 + diff array 누적합 + np.add.at으로 완전 벡터화
- 성능: 진입당 18.4ms → 5.97ms → 0.92ms (20배 개선), 5000회 4.6초
