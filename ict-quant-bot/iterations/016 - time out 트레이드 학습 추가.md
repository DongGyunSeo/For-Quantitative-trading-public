## 🧪 Iteration 016: time out 트레이드 학습 추가
------------------------------------------------------------

### 문제
- 데이터 부족 및 base 승률 부족

### 해결
- time out(30m)된 트레이드의 최대 미실현이 1.1~1.5R이상일때 win 데이터로 추가
- TP 설정 로직에서의 if not TP: 1.5R TP fallback 을 1.2R로 하향

### 인사이트
- 확실한 진입의 트레이드가 아니라면 모델이 더 복잡해짐. noise 학습도가 높아져서 roll back
- AUC 희석으로 인한 머신 혼란 가중
- time_out_pnl avg R = -0.54
