## 🧪 Iteration 018: FVG 선택 로직에 대한 고찰
------------------------------------------------------------

### 문제
- 진입의 품질보다 진입 가격의 품질의 퀄리티가 떨어진다고 판단
- 진입가가 비싸짐 -> SL이 멀어짐 -> 1.5R 이상의 TP 후보를 고르는데 멀어진 SL로 인해 TP가 굉장히 멀어짐

### 해결
- 기존 FVG 선택로직인 가장 비싼 가격의 FVG edge를 선택하는 대신 가장 강한 FVG를 선택하도록 유도
- 23,000건의 데이터를 확인, sweep to displacement 되돌림 비율(0.4~0.7)에서 유의미한 높은 승률을 발견
- displacement 중 생긴 모든 FVG에 대하여 mid와 현재가와 가장 가까운 edge는 모두 진입 가격 후보
- 되돌림 비율 승률 기반으로 linear interpolation하여 보간한 데이터 / LVN 강도 / FVG size 로 점수를 4:3:2로 가중하여 점수제 도입
- FVG는 그 FVG의 가격을 한번 떠나야 FVG를 발견했다고 인정. 점수 계산후 가장 높은 점수의 가격에서 진입

### 인사이트
- 트레이드 수 : 23,324 -> 20,200 (-13%)
- Binary WR : 22.1% -> 27.8% (+5.7pp)
- Timeout WR : 17.9% -> 57.2% (+39.3pp)
- Timeout avg_pnl_r : +4.30R
- 전심볼 양수
- 진입 품질에서 진입 가격의 품질을 고려한 첫번째 진전
- 트레이드 수와 WR의 트레이드 오프
- Timeout에도 유의미한 수익이 있으므로 머신러닝 학습에 포함시키는 방향 추진
