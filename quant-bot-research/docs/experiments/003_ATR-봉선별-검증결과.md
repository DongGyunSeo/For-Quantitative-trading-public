# ATR 봉 선별 검증 결과 (2026-08-19)

질문: **"4H 15봉 AVG ATR 이상인 봉 / ATR 상위 25% / 상위 10% 에서만 거래하면 나아지는가?"**
답: **그렇다. 방향·단조성·대조군이 모두 일치한다. 다만 아직 손익분기 직전이다.**

## 데이터 (교체됨 — 완전 out-of-sample)

새 CSV 10심볼 = **2023-11-18 ~ 2026-07-05**. 직전 검증(2021-04 ~ 2023-12)의 **직후 기간**이라
겹치지 않는 전진 검증 구간이다. 품질은 전부 통과 (coverage 100%, 결측·중복·OHLC 위반 0,
거래량 0 봉도 0건).

기준선 gross 기대값이 직전 기간 +0.014R → 이번 기간 +0.020R 로 재현. 기간 간 일관성 확인.

## 구현

- `qbot/data/features.py` — HTF 봉 파생 지표. 전부 인과적.
  - `atr` = 직전 15봉 TR 평균 (**현재 봉 제외**, `shift(1)`) ← "15봉 기준 AVG ATR"
  - `tr_atr` = TR / ATR — 이 봉이 최근 평균의 몇 배인가
  - `tr_atr_rank` = `tr_atr` 의 **롤링 백분위** (창 500봉 ≈ 83일, 최소표본 100)
    전체 표본 분위수를 쓰면 룩어헤드다. 반드시 롤링.
- `qbot/strategy/filters.py` — `ATRFilter` 등. `Context -> bool` 콜러블.
- 엔진: `BacktestConfig.entry_filter` 가 False 면 `on_bar` 자체를 호출 안 함.
  → 진입 전략은 그대로 두고 봉 선별만 바꿔 A/B 가능. `result.pass_rate` 로 통과율 확인.

## 결과 (4H, 시장가 continuation 진입, 10심볼)

| 필터 | 통과율 | 거래수 | 승률 | 페이오프 | **gross R** | 수수료부담 | **net R** | 수익 양수 심볼 |
|---|---|---|---|---|---|---|---|---|
| 하위25% (대조) | 24.4% | 5,154 | 37.9% | 1.10 | **-0.004** | 0.248 | -0.251 | 0/10 |
| 전체 (기준선) | 100% | 16,196 | 40.2% | 1.14 | **+0.020** | 0.165 | -0.145 | 0/10 |
| TR ≥ AVG_ATR | 39.5% | 5,708 | 42.8% | 1.19 | **+0.050** | 0.102 | -0.052 | 2/10 |
| **상위 25%** | 24.7% | 3,479 | 43.9% | 1.21 | **+0.061** | 0.086 | -0.026 | 3/10 |
| **상위 10%** | 10.0% | 1,293 | 45.0% | 1.21 | **+0.057** | 0.063 | **-0.006** | 6/10 |

## 왜 믿을 만한가

1. **단조성**: 하위25% → 전체 → TR≥ATR → 상위25% 로 gross 가 단조 증가 (-0.004 → +0.061),
   상위10%에서 포화.
2. **대조군이 예측대로 움직임**: 작은 봉만 고르면 gross 가 0으로 떨어지고 수수료부담은
   0.248R 로 **두 배**가 된다. 큰 봉이 좋으면 작은 봉은 나빠야 한다 — 그렇게 나왔다.
3. **승률과 페이오프가 동시에 개선** (40.2%/1.14 → 45.0%/1.21). 한쪽만 오르면 상쇄 아티팩트지만
   둘 다 오르는 건 다르다.
4. **페어 비교**: 10심볼 중 8개가 기준선보다 개선. 대조군은 2개뿐.
5. **아웃라이어 의존 없음**: DOGE(gross +0.237) 제외해도 0.011 → 0.051R 유지.
   TRX 까지 제외해도 0.011 → 0.058R.

## 두 가지 메커니즘이 겹쳐 있다

- **수수료부담 반감 (0.165R → 0.063R)** — 기계적으로 보장됨. 큰 봉 = 넓은 피보 레인지 =
  넓은 SL = 큰 1R = 고정 bps 수수료의 비중 감소.
- **gross 기대값 3배 (0.020R → 0.057R)** — 이쪽이 진짜 발견. 통계적으로는 *시사적*이지
  결정적이진 않다. 상위25% 는 t≈3.0 이지만 심볼 간 상관을 무시한 낙관적 수치이고,
  상위10% 는 표본이 1,293건뿐이라 t≈1.6.

## 지정가(maker) 진입에서는 효과가 약함

같은 필터를 `fib_limit`(0.5 되돌림 지정가)에 걸면 gross 는 -0.012 → +0.003R 로 미미하고,
대조군도 분리되지 않는다(10심볼 중 4~6개만 개선). 큰 봉의 50% 되돌림은 그 자체가 큰 움직임이라,
체결될 때쯤 임펄스가 소진되는 것으로 보인다. **ATR 선별은 시장가 추세 추종 진입과 궁합이 맞는다.**

## 현재 위치와 다음 한 수

net -0.145R → **-0.006R**. 손익분기까지 남은 격차의 96%를 봉 선별만으로 메웠다.

남은 0.006R + 안전마진을 메울 가장 큰 레버는 **진입 체결 방식**이다.
상위10% 에서 수수료부담이 아직 0.063R 인데, 이게 maker 로 바뀌면 ~0.025R → **net ≈ +0.03R**.
다만 `fib_limit` 식 되돌림 지정가는 gross 를 깎으므로,
**HTF 종가 근처에 post-only 지정가를 걸고 미체결 시 스킵**하는 방식이 필요하다
(선택된 봉 자체는 그대로 두고 체결 비용만 낮추는 설계).

부차 항목:
- **TRX 제외 검토** — 전 조합에서 유일하게 일관 음수. 변동폭이 작아 수수료부담이 0.14~0.18R.
  심볼 레벨 `min_range_pct` 게이트로 자동 배제 가능.
- 상위10% 는 심볼당 129건뿐. 파라미터를 더 조이기 전에 표본을 늘릴 것
  (심볼 추가 또는 상위25% 유지).
