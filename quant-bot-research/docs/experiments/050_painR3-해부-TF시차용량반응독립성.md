# painR3 해부 — TF · 시차 · 용량반응 · 독립성

**결론: 느린 상태량이 맞고, 개수 정보에 없는 것을 갖고 있다.**

추세·변동성·쏠림·생존자수·쏠림×수익 상호작용·**개수불균형**·평균보유를 전부 제거한
잔차가 여전히 **+0.2797 (t 7.32, 10/10 심볼, 3.8 위약-σ)** 을 낸다.
확장창 직교화(계수를 과거로만 적합)에서도 +0.2914 로 동일하다.

- 산출물: `out/pain_anatomy.html`
- 코드: `examples/pain_anatomy.py`, `examples/pain_anatomy_verify.py`
- 테스트: 353 통과

잣대: (모멘텀 × 봉폭) 고정 5분위 스프레드 @ 4시간, 단위 = 일간 5m ATR,
클러스터 = (심볼 × 월), 10심볼 × 5.3년.

---

## A. TF 분해 — 5m·15m 이 일한다

구조 손절 3종(`ma_cross_struct` · `rsi_band` · `pivot_break`)을 TF 하나로 제한:

| TF | 스프레드 | t | 심볼+ |
|---|---:|---:|---:|
| 5m | +0.1174 | 4.17 | 8/10 |
| **15m** | **+0.1660** | **4.03** | **10/10** |
| 1h | +0.0519 | 0.94 | 7/10 |
| 4h | +0.0989 | 1.04 | 5/10 |
| 1d | +0.3845 | 2.63 | 8/10 |
| **5개 합산** | **+0.2797~0.3011** | **6~7** | **10/10** |

- **5m·15m 이 견고**하다. 15m 은 t 4.03 에 **10/10**.
- **1h·4h 는 잡음** (t ≈ 1, 5~7/10). 중간 TF 에 정보가 없다는 건 의외다.
- **1d 는 값이 가장 크지만(0.3845) 생존자가 3명뿐**이라 점수가 거칠다.
  t 2.63 은 실재를 시사하지만 크기는 과대평가일 것이다.
- **합치면 어느 하나보다 낫다** — 상보적이라는 뜻이다.

> 이건 VP 검증에서 나왔던 "5m·15m 에만 고유 정보가 있다" 와 같은 모양이다.

4시간 보유 설정과 자연스럽게 맞물린다.

## C. 용량반응 — 꼬리에서 단조, 그리고 비대칭

직교화한 painR3 분위별 4시간 평균수익 (raw, 부호 미적용):

| 분위 | 평균 | | 꼬리 | 평균 | n |
|---|---:|---|---|---:|---:|
| d0 | −0.157 | | 하위 5% | −0.193 | 252,268 |
| d1 | −0.061 | | 상위 5% | +0.291 | 252,268 |
| d3 | +0.184 | | 하위 2% | −0.198 | 100,909 |
| d5 | −0.033 | | 상위 2% | +0.322 | 100,909 |
| d6 | −0.123 | | 하위 1% | −0.181 | 50,455 |
| d9 | +0.216 | | **상위 1%** | **+0.382** | 50,455 |

- **가운데 10분위는 들쭉날쭉하다** (d3 +0.184, d6 −0.123). 선형 신호가 아니다.
- **상위 꼬리는 단조로 세진다**: 5% +0.291 → 2% +0.322 → 1% **+0.382**
- **하위 꼬리는 −0.19 에서 포화**한다
- **비대칭이다.** 숏이 심하게 물린 쪽(상위)은 계속 세지고, 롱이 물린 쪽은 멈춘다

상위 1% 는 왕복 수수료 0.34 ATR 을 넘는다(+0.042 순). 다만 **결과를 보고 고른 칸**이고,
4시간 보유에 봉마다 신호라 50,455건 중 독립 표본은 훨씬 적다. **사전등록 없이는 못 쓴다.**

## D. painR3 는 무엇을 재는가

### 의심했던 것: 쏠림 × 수익의 재서술

분자가 `(close − entry)·side` 이므로, 집단이 한쪽으로 쏠려 있으면
`painR3 ≈ −(최근수익) × 쏠림` 이 될 수 있다. 직접 만들어 봤다.

| 변수 | 상관 |
|---|---:|
| **개수불균형** | **+0.769** |
| 모멘텀 1d | +0.150 |
| 모멘텀 7d | +0.097 |
| 방향쏠림 | −0.078 |
| 미실현이익불균형 | −0.054 |
| 모멘텀 30d | +0.028 |
| 봉폭/ATR | −0.021 |
| ATR비 | −0.009 |
| **쏠림 × 수익 7d** | **−0.008** |
| 평균보유 | +0.006 |
| **쏠림 × 수익 1d** | **+0.004** |
| 생존자수 | +0.002 |

**의심은 틀렸다 — 상관 +0.004.** 그리고 변동성·생존자수·평균보유와도 사실상 무관하다.
유일하게 큰 것은 **개수불균형 +0.769** 다.

### 단계별 설명력

| 설명변수 | R² |
|---|---:|
| 추세만 (1d/7d/30d) | 0.027 |
| + 변동성 (봉폭·ATR비) | 0.028 |
| + 쏠림·생존자수 | 0.095 |
| + 상호작용·**개수불균형**·평균보유 | **0.610** |

R² 가 0.095 → 0.610 으로 뛰는 것은 거의 전부 **개수불균형** 때문이다.
즉 painR3 는 **60% 가 "몇 명이 물렸나", 40% 가 "얼마나 물렸나"** 다.

### 결정적 검정 — 전부 제거해도 남는가

| 잔차 | 스프레드 | t | 심볼+ |
|---|---:|---:|---:|
| 추세만 제거 | +0.3011 | 6.05 | 10/10 |
| **전부 제거** | **+0.2797** | **7.32** | **10/10** |

**효과가 거의 줄지 않는다** (0.301 → 0.280). 상관 0.769 인 개수불균형까지 빼도
그렇다 — **크기 정보가 개수 정보에 없는 것을 갖고 있다.**

(개수 기반 단독은 앞선 문서에서 0.134, painR3 는 0.2525 였다. 여기서 확인된 것은
그 차이가 단순히 "더 정밀한 같은 것"이 아니라 **선형적으로 독립인 성분**이라는 점이다.)

| 어느 TF? | **5m·15m** (1h·4h 는 잡음, 1d 는 크지만 거칠다). 합산이 최선 |
| 오염인가? | **아니다.** 8봉까지 평평, 하루에 소멸. 절벽 없음 |

| 무엇을 재는가? | 60% 는 "몇 명", 40% 는 **"얼마나"**. 그 40% 가 독립적으로 예측한다 |

## G. 다음

1. **상위/하위 1% 를 사전등록하고 전방기록으로 검정.** 용량반응의 비대칭(상위만
   단조로 세짐)은 사전등록할 만한 구체적 예측이다. 이게 전방기록에서 재현되면
   결론이 확정된다. 남은 유일한 검증축이다.
2. **15m 단독 집단을 키워보기.** 15m 이 t 4.03 / 10/10 인데 아키타입이 3종뿐이다.
   구조 손절 계열의 15m 변형을 늘리면 점수 해상도가 올라간다 —
   풍부도 사다리는 평평했지만, 그건 **TF 혼합** 집단에서였다.
3. **비대칭의 원인.** 숏이 물린 쪽만 세지는 것이 펀딩(숏이 롱에게 받는 구간)과
   관련 있는지 확인할 수 있다. 펀딩 실측 데이터는 이미 프로젝트에 있다.
