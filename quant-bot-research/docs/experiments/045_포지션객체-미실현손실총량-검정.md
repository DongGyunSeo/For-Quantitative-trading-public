# 포지션 객체와 Σ|미실현손실|

**개수 대신 크기를 보는 게 맞았다.** 구조 손절 15명 기준으로 신호가 0.134 → **0.2525**
(t 2.94 → **5.73**, 8/10 → **10/10**), 고유분이 0.057 → 0.189 로 **3.3배**가 됐다.
위약 폭 대비 2.6σ → **3.5σ**.

다만 아직 수수료 아래다. 한 다리 기준 0.216 ATR vs 왕복 수수료 0.340 ATR = **0.63배**
(개수 기준 0.33배에서 두 배 가까이 좁혔지만 여전히 1.6배 부족).

- 코드: `qbot/research/trader_pop.py` (`Position`, `positions_frame`, `PainResult`, `population_state`)
- 실행: `examples/trader_pop_pain{,_orth}.py`
- 테스트: 13개 추가 (전체 **315 통과**)

---

## 1. 포지션 객체

요청하신 구조 그대로 만들었다. 한 줄이 한 번의 진입~청산.

```
Position
├── entry_time / entry_price / direction / entry_reason
├── exit_time  / exit_price  / exit_reason
├── risk                 |진입가 − 최초 손절가| = 1R
├── current_pnl          R 단위
├── mae / mfe            최대 역행 / 최대 순행 (R)
├── underwater_duration  연속 수중 봉 수
├── distance_from_entry  |현재가 − 진입가| / R
├── age                  보유 봉 수
└── current_state        이익 / 손실
```

`positions_frame(ltf, archs, atr)` 이 한 장의 DataFrame 으로 낸다.
BTC 전 구간 × 정본 65명 = **355,515 포지션**, 19초.

### 집단의 성격

| 청산 사유 | 비율 |
|---|---:|
| 신호반전 | 67.8% |
| 손절 | 26.4% |
| 지표청산 (채널/SMA5) | 5.6% |
| 시간초과 | 0.3% |

MAE 중앙 **−0.433R**, MFE 중앙 **+0.469R**. 즉 전형적인 포지션은 손절폭의 절반쯤
역행했다가 절반쯤 순행하고 끝난다. 대칭적이고 엣지 없음 — 집단이 "평범한 개미"로
제대로 만들어졌다는 뜻이다.

**핵심 구현 결정**: MAE/MFE 는 에피소드 경계를 파티션으로 삼은 `segment_cummin/cummax`
한 번으로 전부 구한다 (O(n)). 에피소드별 루프 없음.

## 2. Σ|미실현손실| — 네 가지 변형

| 이름 | 정의 | 의도 |
|---|---|---|
| `count` | 물린 사람 **수** 불균형 | 구버전 |
| `painR` | Σ\|손실\| / 각자의 1R | 위험 대비 고통 |
| **`painR3`** | Σ min(\|손실\|, **3R**) | 고통은 포화한다 |
| `painA` | Σ\|손실\| / ATR | 절대 크기 |
| `uw` | Σ 연속 수중 봉 수 | 시간 압력 |
| `gain` | Σ 미실현**이익** 불균형 | 반대편 대조 |

`painR3` 의 3R 상한이 중요하다. 무손절 트레이더는 명목 위험(2×ATR) 대비 수백 R까지
가므로 상한이 없으면 꼬리가 신호를 잡아먹는다 (`painR` t 0.80 vs `painR3` t 3.29).
행동 모델로도 타당하다 — 20R 물린 사람과 50R 물린 사람의 행동은 다르지 않다.

## 3. 함정 하나 — `gain` 은 장기추세였다

1차 측정에서 `gain` 이 **1.3119 (t 4.88, 10/10)** 으로 압도적이었다. 그런데 포지션은
수천 봉 유지된다. 통제에 쓴 모멘텀은 1일짜리였다. 미실현이익이 크다 = 오랫동안 올랐다.

상태량을 **1일·7일·30일 모멘텀(+제곱항)과 봉폭에 대해 직교화**하고 다시 쟀다.

| 상태량 | 직교화 전 | 직교화 후 | 판정 |
|---|---:|---:|---|
| `gain` (CAN) | 1.3119 | **0.2907** | 78% 붕괴 — 추세의 재서술 |
| `gain` (STR) | 0.5333 | 0.1025 (t 1.13) | 소멸 |
| `painR3` (STR) | 0.3030 | **0.2525** | 살아남음 |
| `count` (STR) | 0.1688 | 0.1340 | 살아남음 (더 작게) |

## 4. 결과 — 직교화 후

5분위 스프레드 @4시간, 봉폭 10분위 고정, 클러스터 = (심볼 × 월), 단위 = 일간 5m ATR.

### 구조 손절 15명 (STR)

| 상태량 | 스프레드 | t | 심볼+ | 교차위약 | **고유분** |
|---|---:|---:|---:|---:|---:|
| `count` (구버전) | 0.1340 | 2.94 | 8/10 | 0.0770 | 0.0570 |
| **`painR3`** | **0.2525** | **5.73** | **10/10** | 0.0638 | **0.1886** |
| `painA` | 0.3754 | 3.27 | 10/10 | 0.0691 | 0.3062 |
| `uw` | −0.0910 | −0.47 | 7/10 | 0.0405 | −0.1315 |
| `gain` | 0.1025 | 1.13 | 8/10 | 0.0710 | 0.0315 |
| `net` (고통−이익) | −0.0822 | −0.90 | 9/10 | −0.0661 | −0.0160 |

### 정본 65명 (CAN)

| 상태량 | 스프레드 | t | 심볼+ | 교차위약 | 고유분 |
|---|---:|---:|---:|---:|---:|
| `count` | 0.1831 | 4.87 | 9/10 | 0.0719 | 0.1112 |
| `painR3` | 0.1739 | 3.24 | 9/10 | 0.0414 | 0.1325 |
| `painA` | 0.3068 | 2.39 | 10/10 | 0.0721 | 0.2348 |

### 읽기

1. **크기 > 개수.** STR 기준 `painR3` 가 `count` 를 스프레드 1.9배, t 1.9배,
   고유분 **3.3배**로 이긴다. 심볼 일관성도 8/10 → 10/10.
2. **구조 손절 집단이 정본 전체보다 낫다.** 15명이 65명을 이긴다 (0.2525 vs 0.1739).
   이전 문서의 "구조 손절만 값을 한다"가 크기 측정에서도 재현됐다.
3. **`net` 이 0 이다.** 고통에서 이익을 빼면 신호가 사라진다 →
   **작동하는 것은 손실 쪽뿐**이다. 손실회피(prospect theory)와 일관된다.
4. **시간 압력(`uw`)은 없다.** 오래 물려 있는 것 자체는 정보가 아니다.
   중요한 건 **얼마나** 물렸는가다.

## 5. 검증

| 순환이동 위약 | 값 | t |
|---|---:|---:|
| **정상** | **+0.2525** | **+5.73** |
| 1일 | +0.0160 | +0.38 |
| 7일 | +0.0000 | +0.00 |
| 30일 | +0.0409 | +1.03 |
| 90일 | +0.0596 | +1.56 |
| 180일 | −0.1183 | −2.68 |
| 365일 | +0.0653 | +1.58 |
| 의도적 룩어헤드(+48봉) | **+3.0063** | +59.3 |

위약 평균 +0.011, 폭 ±0.068 → 정상값은 **3.5 위약-SD**. 이전 개수 기반(2.6σ)보다 개선.
룩어헤드 주입 시 12배로 뛰어 측정 민감도 확인.

**단위 테스트**: 에피소드 테이블 ↔ `side5` 완전 복원, 청산사유 ↔ 손절봉 일치,
MAE/MFE ↔ 순수 루프 일치, `Σ|손실|` ↔ 손으로 다시 더한 값 일치(4개 봉),
수중지속 리셋 규칙, 3R 상한 경계. 전체 **315 통과**.

## 6. 수수료 — 아직 아래다

10분위별 4시간 평균수익 (raw, 부호 미적용):

| 분위 | 평균 | | 분위 | 평균 |
|---|---:|---|---|---:|
| d0 | **−0.157** | | d5 | −0.033 |
| d1 | −0.061 | | d6 | −0.123 |
| d2 | +0.054 | | d7 | −0.006 |
| d3 | +0.184 | | d8 | +0.086 |
| d4 | +0.074 | | d9 | **+0.216** |

**단조가 아니다.** 극단 두 분위만 제대로 작동하고 중간은 잡음이다.

최상위−최하위 = **+0.3733 ATR** vs 왕복 수수료 **0.340 ATR** → 1.10배.
**그런데 이 1.10배는 착시다.** 스프레드를 잡으려면 d9 롱 + d0 숏 = **두 번의 거래**이고
수수료도 두 번(0.680) 낸다. 한 다리씩 봐야 한다:

| 다리 | gross | 수수료 | **순** |
|---|---:|---:|---:|
| d9 롱 | +0.216 | 0.340 | **−0.124** |
| d0 숏 | +0.157 | 0.340 | **−0.183** |

여전히 음수다. 다만 개수 기반(0.33배)에서 **0.63배**로 좁혔다.

**메이커 체결(2bps ×2 = 0.194 ATR)** 가정 시 d9 롱은 **+0.022** 로 겨우 양수가 된다.
면도날이고 체결 가정에 전적으로 의존한다.

## 7. 현재 위치와 다음

| 항목 | 상태 |
|---|---|
| 포지션 객체 모델 | 완료 — 355k 포지션, 전 필드 검증 |
| Σ\|미실현손실\| (3R 상한) | **살아남음** — 3.5σ, 10/10, 고유분 0.189 |
| 개수 기반 (구버전) | 열등 — 대체 |
| `gain` / `uw` / `net` | 기각 (추세 재서술 / 무정보 / 상쇄) |
| 수수료 | 0.63배. 메이커 가정으로만 겨우 넘음 |

**다음으로 값이 있는 것 두 가지:**

1. **메이커 진입 실현 가능성 검정.** d9 상태에서 지정가 진입이 실제로 체결되는지를
   5m OHLC 로 근사 검정 (진입가 이하로 내려온 적이 있는가). 이게 되면 엣지가 양수가 된다.
2. **조건변수로 쓰기.** 단독으로는 면도날이지만 모멘텀과 직교(상관 0.06~0.11)하므로
   다른 후보의 필터로 얹으면 겹치지 않는 정보를 더한다.

검증축은 여전히 **전방기록 데이터(2026-08~)** 만 남았다.
