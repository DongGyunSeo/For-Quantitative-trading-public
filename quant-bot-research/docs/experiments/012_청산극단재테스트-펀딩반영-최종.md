# 청산 극단 재테스트 — 수수료 + 펀딩 전액 반영 (2026-08-19)

[`청산이벤트-상위컷-부호반전.md`](011_청산이벤트-상위컷-부호반전.md) 의 후속. 펀딩을 넣으려다 **더 큰 회계 오류** 를 먼저 잡았다.

**결론: 12개 셀 중 딱 하나(vol / 상위1% / TP=2R)만 비용을 넘는다. t=2.12.
그런데 12개를 뒤진 것이므로 다중검정 하에서는 노이즈와 구분되지 않는다. 판정 보류.**

## ⚠ 회계 단위를 틀렸었다 — bps 가 아니라 R

직전 문서에서 "기대 +26.7bps" 라고 적었는데, 그건 **대조군 대비 초과 승률** 에
중앙 R 을 곱한 값이었다. 실제 손익이 아니다. 게다가 이 셋업은 1R 이 60~500bps 로
8배 차이 나서 **bps 평균 = 고정 명목 가정** 이 된다 (큰 R 거래가 평균을 지배).

엔진은 `risk_pct` 사이징 — 거래마다 자본의 일정 비율을 1R 로 건다.
따라서 손익 단위는 **R** 이어야 하고, 수수료·펀딩도 각 거래의 1R 로 나눠 환산해야 한다.

```
순R = 결과R − 수수료bps/1R_bps − 펀딩주기수 × 펀딩bps/1R_bps
```

이렇게 바꾸면 bps 평균이 +5.65 (t=0.48) 이던 셀이 +0.088R (t=2.12) 이 된다.
**분산이 훨씬 작아 t 가 4배 이상 개선된다.** 리스크 고정 사이징의 본래 효과다.

거래별 결과는 `liqevent.trade_outcomes()` 로 뽑는다 (`summarize_liq` 와 판정 일치
회귀 테스트 포함 — 밖에서 다시 세다가 int32 오버플로우 버그를 냈던 전례가 있다).

## 수수료 모델 (OKX 선물)

| 구간 | 비용 |
|---|---|
| 진입 (시장가) | taker 5bps + 슬리피지 1bps |
| TP 청산 (지정가) | maker 2bps |
| SL/기타 청산 (시장가) | taker 5bps + 슬리피지 1bps |

거래당 왕복 9.8~10.9bps. 1R 대비로는 **0.072~0.103R**.

## 펀딩 — 요율을 가정하지 않고 손익분기를 역산

요율 데이터가 없으므로 8시간 정산 시각(00/08/16 UTC) **통과 횟수** 만 센다.
이 셋업은 76%가 숏이고 대폭락 직후엔 펀딩이 음수(숏이 지급)가 되는 경향이므로
**항상 지급(불리)** 을 기본 가정으로 둔다.

| 셋업 | 보유(중앙) | 펀딩 통과 평균 | 통과 0회 비율 |
|---|---|---|---|
| vol 상위1% TP1R | 3.2h | 1.09회 | 51% |
| vol 상위1% TP2R | 5.9h | 1.75회 | 37% |
| vol 상위3% TP2R | 4.8h | 1.58회 | 41% |
| cisd 상위3% TP2R | 3.5h | 1.17회 | 47% |

## 왜 판정을 보류하는가

1. **다중검정.** 2 트리거 × 2 컷 × 3 TP = 12셀을 봤고 그중 최대 t 가 2.12 다.
   상관된 12개 검정에서 기대되는 최대 t 가 대략 2.0~2.4 이므로, **이 값만으로는
   노이즈와 구분되지 않는다.**
2. **표본이 가장 작은 셀만 산다.** 상위3%(n=3,270)는 +0.005R(t=0.21) 로 0 이고,
   상위1%(n=1,240)만 +0.088R 이다. 표본을 3배 늘리면 사라지는 엣지는 의심스럽다.
3. **심볼 상관.** 10심볼 실효 표본은 명목의 1/3~1/5. t=2.12 → 실효 1.0~1.3.
4. 직전 문서의 시간분할에서 vol 상위1% 는 후반에 절반으로 감쇠했다(p=0.10).
5. 상위0.1%(n=114)에서는 아예 무너진다 — 단조성이 끝까지 가지 않는다.

## 그래도 남는 사실

- 승률 초과 자체는 견고했다 (상위1% 55.85%, 9/10 심볼, p<0.0001, 양 반기 동부호).
- 무너지는 지점은 **수수료** 다. 총 0.165R 중 0.077R 을 수수료가 가져간다.
- 따라서 다음 한 수는 명확하다: **진입 비용 절감.**
  진입을 시장가 대신 지정가로 바꾸면 왕복 10bps → 6bps, 수수료R 0.077 → 0.046,
  순R 0.088 → 0.119 (약 35% 개선). 다만 "극단 재테스트" 는 추격 성격이라
  체결률 손실이 얼마인지 따로 재야 한다.
