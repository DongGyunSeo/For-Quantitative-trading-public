# 종합 — 트레이딩 적용 우선순위 (2026-09-10)

프로젝트 전체(가설 8건 기각, 검증 4건, 스윙 129만 개 센서스)를 **거래에
적용하기 좋은 순서**로 정리. 순위 기준:

1. **대조군 통과** — 거울/위약/기하 대조군을 이겼는가
2. **독립 축 재현** — TF, 심볼, 기간 중 둘 이상에서
3. **경제성** — 1R 대비 수수료. 이 프로젝트에서 가장 많이 죽인 요인
4. **거래 규칙 여부** — 진입·청산이 명시되는가, 아니면 필터/음성 결과인가
5. **검증 여력** — 아직 안 본 데이터가 남아 있는가

---

# 1위 · 큰 레그 뒤 두꺼운 VP → 극단 돌파

**근거**

| TF | 레그 Q4(≈5.3 ATR) 에서 vp_ahead 상위−하위 돌파율차 | t |
|---|---|---|
| 5m | **+5.69 %p** | 14.5 |
| 15m | **+5.25 %p** | 11.2 |
| 1H | +4.55 %p | 4.7 |

- 레그 5분위에 걸쳐 **단조 증가** (Q0 −1.5 → Q4 +5.7). 우연한 한 칸이 아니다.
- 확장(중앙값)도 Q4 에서 +0.21 leg (t 11.0), 15m +0.22 (t 7.6).
- 스윙 **129만 개**, (심볼 × 월) 블록 표준오차.
- **독립 구조물에서 같은 결론**: VP 지지저항 검정에서 근거리 고밀도는
  벽이 아니라 통로였다(5m −2.34%p, 15m −2.31%p, 두 반기 모두). 스윙 센서스는
  전혀 다른 구성물인데 같은 방향을 가리킨다.
- 1R = 레그 = 중앙 5.3 ATR 로 큰 편이라 수수료 부담이 낮을 전망.

**왜 1위인가** — 효과 크기가 이 프로젝트에서 본 것 중 가장 크고(5.7%p),
세 TF 에서 단조적이며, 독립 경로 두 개가 수렴한다.

**아직 아닌 것** — **거래로 계산한 적이 없다.** 순R·수수료·펀딩 미산출,
기간 분할 미실시. 그리고 VP 관련 작업에는 OOS 가 이미 소진됐다.

**다음 한 걸음** — 사전등록: 진입 = 큰 레그(상위 40%) + vp_ahead 상위 40%
스윙의 극단 돌파, SL = 레그 기원 또는 스윙 반대편, TP = first-passage 격자.
검증 축은 **심볼 분할**(대형 5 개발 / 소형 5 확인)로 미리 고정.

# 2위 · 4H 구조 정렬 필터

**근거**

- 정렬(4H 구조 방향 = 15m CHoCH 방향) 15셀 **전부 총R 양수** (+0.031~+0.132)
- 역추세 15셀 **전부 양수심볼 0/10**, TP 2R/3R 은 총R 도 전부 음수
- 정렬 − 역추세 차이가 **TP 가 커질수록 단조 증가**: +0.015 → +0.046 → +0.081
  (되돌림이 아니라 추세추종이라는 방향 증거)
- 4H 필터 제거 대조군도 전 셀 음수 — 필터가 표본을 반으로 줄이면서
  남은 절반의 품질을 실제로 올렸다

**왜 2위인가** — 이 프로젝트에서 **기여가 증명된 유일한 필터**다.
그리고 **추세추종 FVG 의 OOS 는 아직 쓰지 않았다** — 검증 여력이 남은
유일한 후보다.

**막고 있는 것** — 단독으로는 순R 음수. 15m 레그의 1R 이 60~90bps 인데
왕복 수수료 6.9bps 라 R 환산 부담이 0.09~0.15R. 손익분기 1R 은 52~122bps 다.

**다음 한 걸음** — 같은 필터를 **1H CHoCH 레그**로 올려 1R 을 2~3배 키운다.
`1R ≥ 손익분기 bps × k` 를 **사전 게이트**로 규칙에 넣고(사후 분위 선택 금지),
TP 1R 은 뺀다(진입봉 편향에 취약: fib0.7 1R 승률 54.6% → 51.5%).

> ⚠ OOS 독립성 주의: 주말갭·VP 작업으로 OOS 구간을 여러 번 봤다.
> 추세추종 성과 자체는 본 적 없지만, "2021~2023 이 연속 편향 구간" 이라는
> 레짐 지식이 이미 있다. 설계에 그 지식이 새어들지 않게 규칙을 먼저 고정할 것.

# 3위 · VP 근거리 고밀도 = 통로 (지지저항 역부호)

**근거**

| TF | 밀도 Q5−Q1 반전률 | t | 거울 대조군 | 순효과 |
|---|---|---|---|---|
| 5m | −2.54 %p | −5.9 | −0.20 | **−2.34 %p** |
| 15m | −2.68 %p | −4.3 | −0.37 | **−2.31 %p** |

- 두 TF 가 **−2.3%p 로 일치**, 기간 분할도 통과
  (5m 전반 −2.68 / 후반 −2.40, 15m −1.94 / −3.42)
- 거울 대조군이 ~0 이므로 레벨 특정 효과
- 1H·4H 는 표본 부족으로 판정 불가

**왜 3위인가** — 재현성은 최상급이지만 **효과가 작고(2.3%p) 단독 진입 규칙이
아니다.** 1위 후보의 근거로 쓰이는 게 더 적절하다.

**주의** — 반전률 절대값(74~93%)은 신호가 아니라 **기하 인공물**이다.
TF 를 올리면 74.5 → 67.7 → 57.1 → 53.0% 로 50% 에 수렴한다.
층 안의 밀도 기울기만 의미가 있다.

# 4위 · VP 자석 (밀도 → 도달률)

**근거**

| TF | 밀도−거울 | t | 거울 비중 |
|---|---|---|---|
| 5m | +0.059 | 8.9 | 63% |
| 15m | +0.057 | 5.0 | 63% |
| 1H | +0.041 | 1.8 | 68% |
| 4H | +0.027 | 0.6 | 84% |

- 5m·15m 은 두 반기 모두 성립. 1H 는 전반만(+0.100 / −0.017 로 부호 반전).
- raw 효과의 61~63% 는 거리 기울기 인공물이고 레벨 특정분은 +0.06.
- 청산 히트맵은 거울이 125% 를 재현해 정보가 0 이었던 것과 대비 —
  **VP 는 실제로 무언가를 담고 있다.**

**왜 4위인가** — 실재하지만 "가격은 최근 거래가 있던 곳으로 돌아온다" 를
정량화한 것에 가깝다. 목표물 선정에는 쓸 수 있으나 그 자체로 엣지는 아니다.

# 5위 · 65.5시간 창의 약한 연속 경향

**근거** (이동폭 200bps+ 조건, 연속 거래로 계산)

3/7 창이 두 구간 모두 양수. 최고는 목→일 (+0.078 / +0.085, 8·9/10 심볼).
그러나 **어떤 창도 두 구간에서 t>2 를 못 넘는다.**

**왜 5위인가** — 1R 이 464~575bps 라 수수료가 0.02R 로 경제성은 좋지만
신호가 약하다. 요일 특이 현상이 아니라 넓고 얇게 퍼진 경향이다.

**부수** — 금→월(주말)만 반대 방향(연속 최악, IS −0.201/0-10 심볼).
주말이 메움 편향이라는 관찰은 맞지만 거래 가능한 크기가 아니다.

# 방법론 자산 (전략보다 오래 간다)

가설은 8건 모두 기각됐지만 **측정 장치는 검증됐다.** OOS 를 IS 와 같은 코드로
돌려 즉시 판정이 난 것이 그 증거다.

- 미래참조 차단 (`build_ref_map`), 인트라바 모호성 정책, 측정 분해능 게이트
- **세 종류 대조군**: 무작위 진입 / 극단앵커 기하 / 거울(레벨 파괴)
- **R 단위 회계** (bps 평균은 1R 이 8배 차이날 때 고정 명목 가정이 된다)
- **군집 표준오차**: 주 단위(갭), (심볼×월) 블록(스윙), 창 단위(VP).
  명목 n 으로 계산하면 t 가 수십~수백으로 나온다
- **심슨의 역설 방어**: 거리대를 섞으면 −4.7%p (t −28.7) 가짜 신호가 나온다
- 부호 인식 펀딩, DST 처리, 이어붙이기 검사

## 내가 틀렸던 것들 (전부 '좋아 보이는' 방향이었다)

1. **순R 부호 반전** — 수수료를 다시 빼지 않고 net 을 음수화. 없는 후보를
   1위로 부를 뻔했다. 이제 반대 방향은 반드시 거래로 재계산한다.
2. **4H 자석 +0.184** — 심볼당 14창짜리 노이즈였다. 표본 2배에서 +0.027 로
   내려앉고 거울 비중이 5% → 84% 로 뒤집혔다. "방향 참고" 로도 쓰면 안 됐다.
3. **TRX 펀딩 23% 잠식** — 실제 잠식률 0.23%. 손익분기 대비 비율을
   포트폴리오 엣지 대비로 잘못 옮겼다.
4. **bin 해상도** — n_bins=50 으로 돌려 거리 층이 통째로 사라진 채
   "흡인 효과 존재 t=29.8" 을 출력했다. 커버리지 출력을 강제해 막았다.
5. **창 겹침** — step < horizon 이라 이웃 창이 미래 경로를 공유했다.
   고치니 5m 자석이 +0.062 → +0.054 로 내려갔다.

# 권고: 다음 한 수

**1위를 사전등록해서 전략화한다.** 순서:

1. 규칙을 문장으로 먼저 쓴다 (셀 예산 15개 이하)
2. **검증 축을 심볼 분할로 고정** — 대형 5개(BTC/ETH/SOL/XRP/BNB)로 개발,
   소형 5개(DOGE/ADA/LINK/AVAX/TRX)로 단 한 번 확인.
   OOS 기간은 이미 소진됐으므로 이게 남은 유일한 독립 축이다
3. `1R ≥ 손익분기 bps × k` 사전 게이트를 규칙에 포함
4. TP 1R 제외, 2R/3R 만
5. 대조군: 거울(vp_ahead 반전) + 무작위 진입 + 기하

전방 기록(`collect_forward.py`)은 계속 돌려둔다 — 2026-08 부터 쌓이는 구간이
언젠가 진짜 OOS 가 된다.
