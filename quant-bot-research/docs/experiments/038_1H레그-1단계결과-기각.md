# 1H 레그 × 4H 정렬 — 1단계 결과: 기각 (2026-09-10)

사전등록: [`1H레그-4H정렬-사전등록.md`](037_1H레그-4H정렬-사전등록.md) (실행 전 작성)
`examples/mtf1h_run.py --group 대형5 --cache cache`

## 판정: 기각 — 2·3단계로 가지 않는다

주 지표 **fib0.7 × TP3R (정렬)**:

```
순R −0.0123   t −0.22   양수심볼 3/5   1R중앙 91bps   수수료R 0.0973
```

기준(순R>0 & t>2.0)에 미달. 사전등록대로 **소형 5심볼과 OOS 는 건드리지 않았다.**

## 예측이 왜 빗나갔나

| 구간 | 1R | 총R | 수수료R | 순R |
|---|---|---|---|---|
| 15m 레그 (기존) | 63bps | +0.1318 | 0.1454 | −0.0136 |
| **1H 레그 (예측)** | ~180bps | +0.1318 | 0.0500 | **+0.0818** |
| **1H 레그 (실제)** | **91bps** | **+0.0908** | **0.0973** | **−0.0123** |

**두 군데서 빗나갔다.**

**① 1R 이 예상만큼 안 커졌다** (사전등록의 실패 모드 ②가 그대로 실현).

| 진입 | 15m 1R | 1H 1R | 배수 |
|---|---|---|---|
| FVG | 78bps | 136bps | 1.74 |
| fib0.4 | 89bps | 161bps | 1.81 |
| **fib0.7** | 63bps | **91bps** | **1.44** |

시간이 4배면 변동성은 √4 = 2배인데 1.44배에 그쳤다.
`fib0.7` 은 1R = 0.3 × 레그(깊은 되돌림일수록 손절이 가깝다)라 확대폭이 가장 작다.
**주 지표로 고른 셀이 하필 1R 확대에 가장 불리한 셀이었다.**

**② 총R 도 같이 줄었다.** 이게 더 중요하다.

```
수수료 0.1454 -> 0.0973  (−33%)
총R   0.1318 -> 0.0908  (−31%)
```

**둘이 거의 같은 비율로 움직여 순R 은 제자리다.** 15m 의 총 엣지가
TF 에 고유한 것이었지, 레그만 키우면 따라오는 성질이 아니었다.

## 4H 정렬 필터 자체는 1H 에서도 작동한다

총R 기준 `정렬 > 무필터 > 역추세` 순서가 **6셀 중 5셀**에서 유지된다:

| 진입 | TP | 정렬 | 무필터 | 역추세 |
|---|---|---|---|---|
| FVG | 3R | +0.0573 | +0.0300 | +0.0123 |
| fib0.4 | 2R | +0.0600 | +0.0133 | −0.0167 |
| fib0.4 | 3R | +0.0462 | −0.0108 | −0.0471 |
| fib0.7 | 2R | +0.0403 | +0.0078 | −0.0152 |
| **fib0.7** | **3R** | **+0.0908** | +0.0112 | −0.0393 |
| FVG | 2R | +0.0361 | +0.0526 | +0.0598 | ← 유일한 역순 |

주 지표 셀 대조군 순R: 정렬 −0.012 / 무필터 −0.071 (t −2.28) / 역추세 −0.119 (t −2.88).
**필터는 확실히 분리를 만든다. 다만 분리해도 수수료 위로 못 올라간다.**

4H:1H 통과율은 37~39% 로, 15m 때(~47%)보다 오히려 **더 선별적**이었다
(사전등록의 실패 모드 ④는 빗나갔다 — 두 TF 가 가까워도 선별력은 유지됐다).

## 사다리를 한 칸 더 올릴 것인가 — 권장하지 않는다

현 총R 을 유지한다고 가정할 때 순R +0.05 를 만들려면:

```
fib0.7 3R : 총R 0.0908 -> 1R 216bps 필요 (현재 91)
fib0.4 2R : 총R 0.0600 -> 1R 820bps 필요 (현재 161)
```

1R 216bps 는 레그로 환산하면 약 7%, 즉 **4H~1D 스케일**이다.
그런데 15m→1H 한 칸에서 이미 **총R 이 수수료와 같은 비율로 줄었다.**
같은 일이 반복되면 4H 에서도 순R 은 0 근처일 것이고, 표본은 심볼당
100개 이하로 떨어져 판정 자체가 불가능해진다.

**사다리는 여기서 멈추는 것이 맞다.**

## 이 프로젝트의 현재 상태 (정직하게)

가설 9건 기각. 남은 것은 **검증된 필터 하나뿐이고, 그 필터를 얹을
검증된 셋업이 없다.**

```
4H 구조 정렬  = 방향 판별에 실제로 기여한다 (15m·1H 양쪽에서 순서 유지)
그런데         그 위에 올릴 진입 규칙(FVG mid / fib 되돌림)의
              **총 엣지가 수수료를 넘지 못한다** — 두 TF 모두에서
```

필터가 아니라 **기저 셋업**이 문제다. 필요한 것은
"같은 필터에 더 큰 총R 을 주는 다른 진입" 이지, 같은 진입의 다른 TF 가 아니다.
