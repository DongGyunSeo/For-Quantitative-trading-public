# TRX 제외 재집계 — 기록 (2026-08-20)

`examples/trx_exclusion_report.py` / `results_trx_exclusion.csv`

## 결론부터: 내가 제시했던 제외 근거는 틀렸다

나는 "TRX 펀딩 −1.138bps 가 후보 엣지의 약 23% 를 잠식한다" 고 말했다.
부호를 반영해 실제로 계산하니 **틀린 수치였다.**

```
펀딩R 평균 (후보 셀 lb3 상위1% fib0.4 TP2R 연속, n=1650)
  전체  −0.00026 R      ← 엣지 +0.112R 의 0.23%
  TRX만 −0.0079  R      ← TRX 자체 순R −0.031R 의 약 25%
  평균 펀딩 정산 횟수 1.36회
```

23% 는 **TRX 의 손익분기 펀딩 대비 비율**이었지 포트폴리오 엣지 잠식률이
아니었다. 실제 잠식률은 0.23% 다. 두 자릿수 배 틀렸다.

원인: 우리 북이 62~64% 숏이고 `rate > 0` 이면 숏이 **받는다**. 롱이 내는
분과 숏이 받는 분이 거의 상쇄돼 순 펀딩이 0 에 수렴한다. `순R_실측부호`가
`순R_무시`와 소수점 넷째 자리까지 같은 이유다.

## TRX 는 일관되게 나쁘지도 않다

심볼별 순R (실측부호):

```
lb3 상위1% TP2R : TRX −0.034  (최하위)
lb2 상위1% TP3R : TRX −0.177  (최하위)
lb3 상위3% TP2R : TRX +0.027  (10심볼 중 5위 — BTC −0.044, LINK −0.025 보다 위)
```

상위3% 셀에서는 TRX 가 **BTC·LINK 보다 낫다**. "TRX 가 항상 최악" 은
사실이 아니었다.

## 판정

TRX 제외를 정당화할 **사전(ex-ante) 근거가 없다.**

- 펀딩 근거 → 실제 잠식률 0.23%, 무의미.
- 남는 근거는 "TRX 의 거래 성과가 나빴다" 뿐 → 정확히 사후선택(cherry-picking).
- 게다가 셀에 따라 부호가 뒤집힌다.

**주 지표는 10심볼 유지.** 이 문서의 9심볼 수치는 참고 기록이며,
성과 보고에 인용하지 않는다.
