# 1H 레그 × 4H 정렬 — 사전등록 (2026-09-10, 실행 전 작성)

## 가설 (문장)

> 4H 구조 정렬 필터는 기여가 증명됐다. 유일하게 막고 있는 것은 15m 레그의
> 1R 이 60~90bps 로 작아 수수료가 0.09~0.15R 을 먹는 것이다.
> **레그를 1H 로 올려 1R 을 2~3배 키우면 같은 필터가 순R 양수가 된다.**

## 근거 (기존 검증에서 확정된 것만)

- 정렬 총R 전 셀 양수 (+0.037~+0.132) / 역추세 전 셀 음수 / **무필터는 정확히 중간**
- 정렬 − 역추세: fib0.7 TP3R 에서 **+0.176 (t 4.8)**, TP 가 클수록 단조 증가
- 기간 안정성: 전반 +0.137 (t 2.7) / **후반 +0.221 (t 3.8)** — 두 반기 모두 양수
- 심볼 **9/10** 양수 (BNB 만 −0.097)
- 손익분기 1R: FVG 113bps / fib0.4 122bps / fib0.7 **52bps** (현재 중앙 63bps)

fib0.7 TP3R 의 총R 이 +0.132 이므로, 수수료가 0.15R → 0.05R 로 내려가면
순R 은 **+0.08 근처**가 된다. 이것이 검정할 예측이다.

## 변경하는 것: **딱 하나**

```
mtf: "15m"  ->  "1h"
```

체결 대기는 MTF 봉 수를 유지한다 (15m 기준 96개 5m봉 = 32 MTF봉
→ 1H 기준 **384개 5m봉** = 32 MTF봉). 보유 한도는 7일(2016봉) 그대로.
그 외 모든 파라미터는 손대지 않는다.

| 항목 | 값 | 비고 |
|---|---|---|
| HTF 방향 | 4H `structure_breaks` | 검증된 것 그대로 |
| MTF | **1h** | ← 유일한 변경 |
| swing lookback | HTF 2 / MTF 2 | 그대로 |
| 역추세 | 차단 | 그대로 |
| FVG 탐색창 | CHoCH 확정봉 j ~ j+3 | 그대로 |
| 체결 대기 | 384봉 (32 MTF봉) | MTF 비례 |
| 보유 한도 | 2016봉 (7일) | 그대로 |
| 분해능 게이트 | 1R/ATR5m ≥ 2 | 그대로 |
| 손절 | origin (레그 기원) | 주 지표 |
| TP | 2R / 3R | **1R 제외** (진입봉 편향) |
| 수수료 | 진입·TP maker 2bps, SL taker 5+1 | 그대로 |
| 펀딩 | 심볼별 실측 × 포지션 부호 | 그대로 |

**bps 하한 게이트는 넣지 않는다.** 1H 레그가 1R 을 키우는지 자체가 검정 대상인데
게이트를 걸면 그 효과를 인위적으로 만들어낸다. 1R 분포는 결과로 보고한다.

## 셀 예산

```
진입 3종 (FVG, fib0.4, fib0.7) × TP 2종 = 6셀
```

주 지표는 **fib0.7 × TP3R 단 하나**다. 15m 검정에서 정렬 효과가 가장 컸고
손익분기 1R 이 가장 낮았던 셀이라 사전 정보로 지정한다.
나머지 5셀은 보고하되 후보 선정에 쓰지 않는다.

귀무 하 6셀 최대 |t| 기대값 ≈ 2.0~2.3.

## 검증 축: 3단계, 각 단계 **한 번만**

VP 작업으로 OOS 기간을 여러 번 봤으므로 **심볼 분할을 1차 축**으로 쓴다.

```
1단계  개발  대형 5 (BTC, ETH, SOL, XRP, BNB) · IS 2023-11~2026-07
2단계  확인  소형 5 (DOGE, ADA, LINK, AVAX, TRX) · IS      <- 1단계 통과 시에만
3단계  확인  10심볼 · OOS 2021-04~2023-11                   <- 2단계 통과 시에만
```

각 단계는 파라미터 변경 없이 한 번만 실행한다.
1단계가 실패하면 2·3단계로 가지 않고 그대로 기각한다.

## 판정 기준 (실행 전 고정)

주 지표 셀(fib0.7 × TP3R) 기준:

```
통과    순R > 0  &  t > 2.0  &  양수심볼 ≥ 3/5 (3단계는 ≥ 7/10)
약통과  순R > 0  &  t 1.0~2.0
기각    그 외
```

t 는 **(심볼 × 월) 블록 평균의 분산**으로 낸다. 거래를 독립으로 세지 않는다.

## 대조군 (동시 산출)

1. **역추세 미러** — 4H 정렬을 반대로. 정렬이 유의하게 나아야 한다.
2. **무필터** — 4H 필터 제거. 정렬과 역추세 사이에 있어야 한다.
   (15m 에서 실제로 그랬다 — 이 구조가 유지되는지가 핵심 점검이다)

## 미리 적어두는 실패 모드

- **표본 급감.** 1H CHoCH 는 15m 보다 훨씬 드물다. 15m 에서 심볼당 셋업이
  1,117~2,091개였는데 1H 면 1/4 이하로 떨어질 수 있다. 대형 5심볼만 쓰면
  더 줄어든다. **셋업 수를 먼저 보고한다.**
- **1R 이 예상만큼 안 커질 수 있다.** 레그 크기는 ATR 대비로 재는데
  1H ATR 자체가 크므로 bps 기준 1R 이 4배가 아니라 2배에 그칠 수 있다.
- **체결률 하락.** 1H 레그의 fib 0.7 되돌림은 15m 보다 깊고 오래 걸린다.
  32 MTF봉(32시간) 안에 체결되지 않는 비율이 늘 수 있다.
- **4H:1H 비율 문제.** 15m 일 때 HTF:MTF = 16:1 이었는데 1H 면 4:1 이다.
  두 TF 가 가까워져 정렬 필터의 선별력이 떨어질 수 있다. **통과율을 보고한다.**

## 실행 전 상태 기록

이 문서 작성 시점에 1H 레그는 **한 번도 실행한 적이 없다.**
소형 5심볼과 OOS 는 이 가설로 건드리지 않았다.
