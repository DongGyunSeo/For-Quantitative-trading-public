# 손절가 확률분포와 거래량·봉크기 실증

**분포는 만들 수 있다. 그런데 실증은 반대로 나왔다.**

앞쪽에 대기 손절이 많이 쌓여 있을수록 그 구간을 지날 때 거래량이 **더 적었다**
(log −0.090, t −56.9, **10심볼 전부 음수**). 순환이동 위약은 +0.001 (t 0.86) 로 정상.
손절을 "연료"로 보는 ICT 전제는 이 측정에서 지지되지 않는다.

- 코드: `qbot/research/trader_pop.py` (`stop_density`), `examples/trader_pop_volume{,_report}.py`
- 산출물: `out/stop_density.html` (시간×가격 밀도맵 · 계열별 분포 · 검정 결과)
- 테스트: 4개 추가 (전체 **302 통과**)

## 1. 손절가 확률분포 — 만들 수 있다

`run_population` 이 "이 봉에서 몇 명이 털렸나"(사후)를 세는 것과 달리,
`stop_density` 는 **"지금 어느 가격에 몇 개의 손절이 대기 중인가"**(사전)를 낸다.

봉마다 살아있는 트레이더의 손절가를 모아 가격축에 담는다. 거리는 ATR 정규화(대역 질량)와
% of price(프로파일) 두 축 모두 제공한다. 65명 × 552,960봉 = **18초**.

### 현재가 대비 분포 (BTC 전 구간, 시간평균 명수)

| 구간 | 질량 | | 구간 | 질량 |
|---|---:|---|---|---:|
| −15 ~ −10% | 6.14 | | +0 ~ +0.5% | 1.83 |
| −10 ~ −6% | 1.98 | | +0.5 ~ +1% | 1.66 |
| −6 ~ −4% | 1.14 | | +1 ~ +2% | 1.93 |
| −4 ~ −2% | 2.06 | | +2 ~ +4% | 2.01 |
| −2 ~ −1% | 1.96 | | +4 ~ +10% | 2.97 |
| −1 ~ −0.5% | 1.69 | | +10 ~ +15% | 5.74 |
| −0.5 ~ 0% | 1.82 | | **총** | **32.9** |

거의 완벽히 대칭이고, 현재가 바로 옆(±0.5%)이 가장 두껍다. 바깥 꼬리는 고정%(−10/−25%)
손절을 쓰는 트레이더들이 만든다.

### 계열별 모양이 다르다

- **트레일**: 현재가 바로 옆에 뾰족하게 (래칫이 가격을 따라오므로)
- **구조 / ATR고정**: ±0.5~2% 에 완만한 봉우리
- **고정%**: ±10% 에 두 개의 혹
- **무손절**: 0 (당연 — 손절 주문이 없다)

### 밀도맵의 성질 — 자석이 아니라 그림자

시간×가격 히트맵을 보면 띠가 **가격을 따라 이동한다**. 고정된 자석이 아니다.
이건 청산 히트맵이 죽었던 이유("그냥 최근에 가격이 있던 곳")와 같은 구조적 위험 신호다.

## 2. 실증 설계 — 수익률이 아니라 **체결 흔적**

손절은 시장가 주문이다. 정말 그 가격에 쌓여 있었다면 체결될 때
(1) **거래량이 튀고** (2) **봉이 확대**되어야 한다. 수익률과 달리 이건 기하학 설명과
독립적인 다른 데이터 열(거래량)이다.

10분위 매칭으로는 통제가 샌다 — 거래량과 봉폭의 관계는 연속·비선형이고 최상위 분위 안의
변동폭이 분위 간 변동폭만큼 크다. 그래서 **회귀 잔차**로 통제했다.

```
log(상대거래량) ~ log(봉폭) + log(봉폭)² + 시각더미(24) + 요일더미(7)
```

잔차에 대해 5분위 스프레드. 클러스터 = (심볼 × 월), 596 클러스터.

## 3. 결과

| 검정 | 집단 | 스프레드 | t | 심볼+ |
|---|---|---:|---:|---:|
| **T1 동시**<br>체결 손절 → 거래량 | 상태없는 경쟁자 | **+0.356** | 81.2 | 10/10 |
| | 구조 손절 15명 | +0.046 | 9.0 | 10/10 |
| | 정본 집단 65명 | −0.066 | −19.0 | 0/10 |
| **T3 봉폭**<br>체결 손절 → 봉폭 | 상태없는 경쟁자 | **+0.316** | 51.0 | 10/10 |
| | 정본 집단 65명 | +0.131 | 47.6 | 10/10 |
| | 구조 손절 15명 | +0.130 | 31.3 | 10/10 |
| **T2 예측 (아래)**<br>대기질량 → 이후 1h 거래량 | 정본 집단 65명 | **−0.090** | −56.9 | 0/10 |
| | 구조 손절 15명 | −0.082 | −37.2 | 0/10 |
| | 위약(30일 순환이동) | +0.001 | 0.86 | 7/10 |
| **T2 예측 (위)** | 정본 집단 65명 | −0.093 | −54.1 | 0/10 |
| | 구조 손절 15명 | −0.081 | −40.3 | 0/10 |
| | 위약(30일 순환이동) | −0.001 | −0.70 | 4/10 |

(로그 단위. +0.356 ≈ 거래량 +43%)

### 읽기

1. **레벨 돌파의 주문 흐름은 실재한다.** 상태 없는 경쟁자(롤링 10/20/50봉 극단 돌파)는
   봉폭·시각·요일을 통제하고도 거래량 **+43%**, 봉폭 **+37%** 를 설명한다. 크고 명확하다.
2. **시뮬레이션 트레이더의 손절맵은 거기에 얹히지 못한다.** T1 에서 구조 손절 15명은
   +0.046 으로 경쟁자의 1/8, 정본 65명은 오히려 음수다.
3. **예측형(T2)에서는 부호가 뒤집힌다.** 앞에 대기 손절이 많을수록 그 구간을 지날 때
   거래량이 **줄어든다**. 위쪽/아래쪽이 −0.090 / −0.093 으로 **완벽히 대칭** —
   방향성 편향이 아니라 상태 효과다.

### 통제 사다리 — 부호는 원시 데이터에 이미 있다

| 통제 | 스프레드 | t |
|---|---:|---:|
| ① 원시 (통제 없음) | −0.130 | −51.5 |
| ② +이동폭만 | −0.102 | −47.8 |
| ③ +현재거래량만 | −0.118 | −72.4 |
| ④ +시각/요일만 | −0.104 | −44.1 |
| ⑤ 전부 | −0.090 | −56.9 |

통제가 부호를 만든 게 아니다. 원시에서 −0.130 이고 통제는 **0 쪽으로 줄일 뿐**이다.

## 4. 해석

가장 정합적인 읽기: **현재가 근처의 손절 밀도는 "연료"가 아니라 "압축" 지표다.**

많은 트레이더의 손절이 현재가 가까이 몰려 있다는 것은 시장이 좁은 폭에서 횡보하며
다들 진입 근처에 머물러 있다는 뜻이고, 그런 구간은 이후 활동이 **적다**.
ICT 의 "가격은 손절 군집을 먹으러 간다"는 서사와는 인과 방향이 반대다.

반면 **레벨 돌파**는 진짜다 — 다만 그건 시뮬레이션 트레이더가 필요 없는,
`rolling(n).max()` 한 줄로 얻어지는 것이다.

## 5. 종합 판정

| 항목 | 상태 |
|---|---|
| 손절가 확률분포 생성 | **가능** — 구현·검증 완료, 재사용 가능 |
| 손절 군집 → 반전 (수익) | 기각 (이전 문서) |
| 손절 체결 → 거래량 | 기각 — 단순 기하 경쟁자가 8배 |
| 대기 손절 → 이후 활동 | **역부호로 기각** — 위약 정상, 0/10 심볼 |
| 물린 트레이더(미실현손익) | 유일 생존, 수수료의 1/3 (별도 문서) |

**손절 위치 계열은 여기서 완전히 닫는다.** 세 갈래(수익·체결량·예측)로 모두 검정했고
모두 기각됐다. 남은 것은 손절이 아니라 **포지션 상태**(물림) 쪽이다.
