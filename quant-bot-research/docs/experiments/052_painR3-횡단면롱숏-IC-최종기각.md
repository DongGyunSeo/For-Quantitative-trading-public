# painR3 결산 — 횡단면 롱숏 · 정보계수 · 최종 기각

작성 2026-09-18 · 10심볼 OKX 5분봉 2021-04-02 ~ 2026-07-05 (격자 11,521) · 검정 368 통과

## 결론

**기각.** 신호는 실재하지만 **크기가 1~2 bps** 로, 왕복 비용 8 bps 의 눈금 아래다.
서로 독립적인 네 가지 설계가 모두 같은 크기로 수렴하므로 이건 설계 실패가 아니라
**효과의 참값이 그만큼**이라는 뜻이다. 홀드아웃 12개월에서는 다섯 측정 중 넷이 0 이하.

painR3 계열은 여기서 닫는다.

## 사전등록 (탐색 전 고정, 그대로 지켰음)

| 항목 | 값 |
|---|---|
| 신호 | painR3 워크포워드 잔차(과거 폴드로만 적합) — `results_pain_three_*.npz` 재사용 |
| 줄세우기 | 매 리밸런스 시점의 **횡단면 순위** (심볼별 시계열 분위가 아님) |
| k | 상위/하위 1 · 2 · 3 |
| 리밸런스 | 48봉(4시간), 겹치지 않음 |
| 체결 | 신호봉 종가 지정가(maker 2bps), 12봉 내 미체결이면 그 다리 폐기 |
| 청산 | 체결 후 48봉 시장가(taker 6bps) |
| 포트폴리오 | (롱 다리 평균 + 숏 다리 평균) / 2. 한쪽이 전부 미체결인 시점은 버림 |
| 유니버스 | 10심볼 / 9심볼(TRX 제외) |
| 대조군 | 신호 반전 · 무작위 순위 |
| 판정 | 순 > 0 · 월 클러스터 t > 2 · 홀드아웃도 양수 |

## 1. 횡단면 롱숏 (`examples/pain_cross_section.py`)

10심볼, k=1, 체결률 99.1%.

| 구간 | 변이 | 기간수 | gross | net | t(월) | 승률 |
|---|---|---|---|---|---|---|
| 전체 | **신호** | 9,422 | **+1.05** | −6.95 | −7.69 | 42.5% |
| 전체 | 반전 | 9,410 | −1.59 | −9.59 | −11.43 | 42.1% |
| 전체 | 무작위 | 9,404 | **+0.62** | −7.38 | −8.99 | 42.2% |
| 홀드아웃 전 | **신호** | 7,253 | **+1.48** | −6.52 | −6.12 | 43.2% |
| 홀드아웃 전 | 반전 | 7,239 | −2.12 | −10.12 | −10.04 | 42.3% |
| 홀드아웃 전 | 무작위 | 7,237 | +0.76 | −7.24 | −8.24 | 42.5% |
| 홀드아웃 12개월 | **신호** | 2,169 | **−0.38** | −8.38 | −5.79 | 40.1% |
| 홀드아웃 12개월 | 반전 | 2,171 | +0.16 | −7.84 | −6.08 | 41.6% |
| 홀드아웃 12개월 | 무작위 | 2,167 | +0.15 | −7.85 | −3.64 | 40.9% |

- 신호(+1.05) − 반전(−1.59) = 2.64 → 순수 신호분 **1.3 bps**.
- 그런데 **무작위가 +0.62** 다. 9심볼로 바꾸면 무작위는 −1.61 로 튄다.
  10심볼 횡단면에서 무작위 롱숏의 잡음이 신호와 **같은 눈금**에 있다. 신호/잡음 ≈ 1.
- k 를 키울수록 gross 가 작아진다(k=3 에서 +0.06) — 꼬리에만 있는 효과라는 뜻이고,
  꼬리는 곧 표본이 적다는 뜻이다.
- 홀드아웃에서 신호와 반전의 **부호가 뒤집힌다**.

## 2. 횡단면 정보계수 (`examples/pain_cross_ic.py`)

매 리밸런스 시점 잔차 순위 vs 앞으로 48봉 수익 순위의 스피어만 상관.

**클러스터 눈금에 민감하다.** 월로 묶으면 t 2.40 인데 **분기로 묶으면 t 1.81** (17분기 중 11 양수).

## 3. 네 접근법의 수렴 — 이게 핵심

다리당 gross bps (배리어는 각 시도의 실제 1R bps 로 환산):

| 접근 | 홀드아웃 전 | 홀드아웃 12개월 |
|---|---|---|
| 시계열 꼬리 1% · 롱만 · 48봉 시간청산 | **+5.05** | −1.54 |
| 횡단면 IC 스프레드 | +2.23 | +0.45 |
| 시계열 꼬리 1% · 합계 · 48봉 시간청산 | +2.27 | −1.21 |
| 횡단면 롱숏 top-1 | +1.48 | −0.38 |
| 배리어 2R/1R · 1% 꼬리 | +0.97 | +0.38 |

설계가 서로 독립인데 결과가 한 자리 bps 로 모인다. 이건 "방법을 잘못 골랐다"가 아니라
**모수 추정이 수렴했다**는 신호다. `painR3` 의 4시간 지평 효과 ≈ **1~2 bps**.

## 4. 손익분기 비용

| | |
|---|---|
| 필요 왕복 비용 | **< 1.8 bps** (가장 후한 추정인 횡단면 스프레드 기준) |
| 현재 셋업 | 8.0 bps (maker 진입 2 + taker 청산 5 + 슬리피지 1) |
| 완전 maker 왕복 | 4.0 bps — 여전히 2배 부족 |

**수수료를 0 으로 만들어도 슬리피지만으로 잡아먹힌다.** 4시간 지평에서 구조적으로 거래 불가.
더 긴 지평이 유일하게 남은 문이지만, 시차 프로파일에서 painR3 는 t-288(하루)에 −0.02 로
이미 소멸했다. 문이 닫혀 있다.

## painR3 가 남긴 것 (거래 신호로는 죽었지만 확정된 사실)

| 확정 | 근거 |
|---|---|
| 신호는 실재한다 | 추세·변동성·쏠림·개수·보유기간 전부 제거 후 +0.280 (t 7.32, 10/10, 위약 3.8σ) |
| 느린 상태량이다 | 시차 8봉까지 평평, t-288 에서 소멸 — 진입봉 오염의 모양이 아니다 |
| 비대칭은 시장 탓 | 하락장 −0.008(완전 대칭) / 상승장 +0.465 — 신호 자체는 대칭 |
| 펀딩이 아니다 | 0.07 bps/4h vs 설명해야 할 9 bps — 130배 차이 |
| 크기 ≈ 1~2 bps | 독립적인 네 설계가 같은 값으로 수렴 |

## 이번에 고친 것 / 교훈

1. **`ts` 는 마이크로초였다.** `df.index.view("int64")` 로 저장했는데 인덱스가
   `datetime64[us]` 라서 `pd.to_datetime(ts, utc=True)`(ns 가정)가 1970년을 뱉었다.
   → `npz` 의 `ts` 는 무결성 검사에만 쓰고 인덱스는 `df.index` 를 쓴다.
2. **순위 상관은 교집합 위에서 매겨야 한다.** 각 행렬에서 따로 순위를 매기고
   나중에 결측을 지우면 중심이 어긋나 상관이 틀린다(무작위 데이터에서 최대 0.16 오차).
   → `rowwise_ic` 를 교집합 우선으로 다시 쓰고 scipy `spearmanr` 와 5e-16 까지 대조.
3. **클러스터 눈금을 하나만 보고하지 말 것.** 같은 데이터가 월 t 2.40 / 분기 t 1.81 이다.
   경계선 결과를 유의하다고 부르려면 눈금을 바꿔가며 확인해야 한다.
4. **롱숏은 양쪽 다리가 다 체결돼야 시장중립이다.** 한쪽만 체결된 시점을
   평균에 넣으면 방향 노출이 섞여 들어간다. → 양쪽 평균의 평균으로 고침.
5. **무작위 대조군을 반드시 같이 돌려라.** 이번에는 무작위가 +0.62 를 찍어서
   신호의 +1.05 가 잡음 눈금 위에 있다는 걸 바로 보여줬다. 반전만 봤으면 놓쳤다.
