# 추세추종 FVG 가설 — 사전등록 (2026-08-20, 탐색 전 작성)

지난 여섯 가설이 전부 기각됐고, 마지막 것은 **144셀을 훑어 최대값을 후보로 삼은 것**이
원인이었다. 이번에는 탐색 전에 규칙을 못 박는다. 이 문서를 벗어난 셀은 돌리지 않는다.

## 가설 (문장)

> 4H 구조가 정한 방향으로만, 15m 에서 같은 방향 CHoCH 가 나온 뒤,
> 그 임펄스가 남긴 FVG(없으면 임펄스 레그의 fib 되돌림)에서 지정가로 진입하면
> 추세 방향 이동을 잡을 수 있다.

## 규칙 (전부 고정, 스윕 대상 아님)

| 항목 | 값 | 근거 |
|---|---|---|
| 4H 방향 | `structure_breaks` 의 마지막 확정 브레이크 방향 (BOS/CHoCH) | 사용자 지정 |
| 4H swing lookback | 2 | 15m 과 동일 엔진·동일 값. 스윕 안 함 |
| 15m swing lookback | 2 | 직전 검정에서 쓰던 값 그대로 |
| 역추세 | **차단** (15m CHoCH 방향 ≠ 4H 방향이면 폐기) | 사용자 지정 |
| FVG 탐색창 | CHoCH 확정봉 j 부터 j+3 (15m) 중 **첫 번째** 동방향 FVG | j 이전 FVG 는 임펄스가 남긴 게 아니다 |
| FVG 진입가 | FVG mid | 직전 FVG 가설과 동일 규약 |
| fib 대체진입 | 레그 [최근 스윙 극단 → CHoCH 이후 트레일링 peak] 의 0.4/0.5/0.6/0.7 | 사용자 지정 |
| 체결 대기 | 96봉 (8h, 5m 기준) | 고정 |
| 보유 한도 | 2016봉 (7일) | 고정 |
| 측정 분해능 | 1R/ATR5m ≥ 2 | 기존 규칙 |
| TP | 1R / 2R / 3R (first-passage 격자로 사후 재구성) | 기존 규칙 |
| 인트라바 | SL_FIRST | 기존 규칙 |
| 수수료 | 진입·TP maker 2bps, SL taker 5+1bps | 기존 규칙 |

## 손절 3종 (사용자 지정: 세 가지 다 기록)

| 이름 | 정의 | 비고 |
|---|---|---|
| `origin` | 레그 기원 = CHoCH 이전 마지막 확정 15m 스윙 극단 | **주 지표** |
| `impulse` | 브레이크된 스윙 봉 ~ CHoCH 확정봉 사이의 반대편 극단 | 두 모드 공통 |
| `fvg` | FVG 반대편 edge | **FVG 모드에만 적용**, fib 모드는 NaN |

## 셀 예산

```
주 지표 : 진입 5종(FVG, fib 0.4/0.5/0.6/0.7) × TP 3종 = 15셀   (손절 origin 고정)
보조    : 손절 impulse/fvg 로 각각 15셀 = 추가 30셀
총      : 45셀
```

귀무 하에서 45셀의 최대 |t| 기대값은 약 2.6~3.0.
따라서 **주 지표 15셀 중 t > 3.0 인 셀이 있을 때만 OOS 로 넘어간다.**
보조 30셀은 기록만 하고 후보 선정에 쓰지 않는다 (여기서 최대값을 고르면
지난번과 같은 실수다).

## OOS 잠금

`cache_oos/` (2021-04 ~ 각 심볼 IS 직전) 는 **후보가 확정되기 전까지 건드리지 않는다.**
후보 확정 후 단 한 번, 파라미터 변경 없이 실행한다. 결과가 나쁘다고 다른 셀을
꺼내지 않는다.

## 대조군 (전략과 동시에 산출)

1. **역추세 미러** — 4H 정렬을 정반대로 뒤집어 같은 규칙 실행.
   추세추종이 근거라면 이쪽은 명확히 나빠야 한다. 비슷하면 4H 필터는 장식이다.
2. **4H 필터 제거** — 방향 필터 없이 15m CHoCH 만. 4H 필터의 순 기여를 잰다.
3. **risk_bps 정합 무작위 진입** — 같은 1R 대역에서 무작위 시점 + 동일 배리어 기하.
   1R 분포를 맞추지 않으면 수수료 차이를 전략 차이로 오독한다 (OOS 검증에서 실제로 그럴 뻔했다).

## 판정 기준 (실행 전 고정)

```
OOS 진출  주 지표 15셀 중  순R > 0 & t > 3.0 & 양수심볼 ≥ 7/10
          그리고 역추세 미러보다 유의하게 우월
보류      t 2.0~3.0
기각      그 외
```

## 미리 예상되는 실패 모드 (나중에 변명하지 않기 위해 적어둔다)

- **FVG 모드 표본 부족** — CHoCH 후 3봉 안에 FVG 가 없는 경우가 많으면 fib 모드만 남는다.
  그러면 이건 'FVG 가설' 이 아니라 'fib 되돌림 가설' 이다. 표본 수를 먼저 보고한다.
- **1R 이 너무 작음** — fib 0.4 진입 + origin 손절이면 1R 이 레그 전체라 크지만,
  FVG mid 진입 + FVG edge 손절이면 1R 이 매우 작아 5m 분해능에 걸린다.
  `1R/ATR5m ≥ 2` 게이트에 몇 %가 걸리는지 반드시 보고한다.
- **4H 필터가 표본을 과하게 깎음** — 정렬 조건이 표본을 1/3 이하로 줄이면
  검정력이 사라진다. 통과율을 보고한다.
