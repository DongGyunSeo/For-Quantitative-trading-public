## 2. 봉인 규칙 (2026-09-25 부터, 문서 61)

- **분석 창**: 2021-04-02 ~ 2026-07-05 00:00 UTC (00:00 봉 포함). 분석 스크립트는 읽자마자 `--until` 로 잘라낸다.
- **봉인 창**: 2026-07-05 00:05 ~ 2026-09-24 (81일). 가설과 규칙을 확정한 뒤 **사용자 확인을 받고 딱 한 번** 연다. **아직 열지 않았다.**
- 81일로는 작은 효과를 확인할 수 없다 — **큰 실패만 거를 수 있다.** (예: 시계열 추세 11주로는 "주평균이 −4% 보다 나쁘면 기각" 정도)

## 3. 원자료 받는 법

자세한 사용법: 문서 [59](experiments/059_OKX-5분봉-수집기-사용법.md) (심볼당 약 4분, 결과 `cache_okx/<심볼>_5m_futures.csv.gz` + `manifest.json`).
감사는 `tools/data_audit.py`(표시만 하고 지우지 않는다). 클라우드에선 OKX 호출이 막혀 **사용자 PC 에서** 돌렸다.

```bash
# 1) 사용자 PC 에서 (클라우드에선 OKX 호출이 막힐 수 있다) — 문서 59
pip install requests
python tools/okx_collect.py probe
python tools/okx_collect.py universe --top 50 --start 2021-04-02 --min-list-date 2021-04-02
python tools/okx_collect.py collect          # 심볼당 약 4분, --max-hours 4 로 나눠 돌릴 수 있다
python tools/okx_collect.py verify
# 결과 okx_data/raw/{심볼}_5m_futures.csv.gz → 이 폴더의 cache_okx/ 로 옮긴다 (+ manifest.json)

# 2) 감사 — 표시만 하고 지우지 않는다
python tools/data_audit.py audit             # → results_data_audit.csv · results_data_audit_events.csv
python tools/data_audit.py overlap           # 10심볼 캐시(cache_all/)와 겹치는 구간 대조 (선택)
```

- 다시 받은 원자료는 같은 값이어야 한다(문서 [61](experiments/061_OKX-47심볼-데이터감사-및-봉인규칙.md): 기존 10심볼 캐시와 겹치는 480만 봉에서 불일치 0). 숫자가 다르면 먼저 `tools/data_audit.py overlap` 으로 원자료를 대조한다.
- 초기 10심볼 데이터(`cache_all/`, 문서 2 ~ 58)는 claude.ai 프로젝트 파일 `*_5m_futures_oos.csv`(OOS) + `*_5m_futures.csv`(IS)를 이어 붙인 것이다(문서 [55](experiments/055_코드베이스-유실-및-재구축-검수.md)). 커밋하지 않는다.
