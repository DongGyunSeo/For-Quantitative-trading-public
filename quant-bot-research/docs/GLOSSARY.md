# 용어집

← [README](../README.md) · [연구 규약](METHODOLOGY.md)

| 용어 | 뜻 |
|---|---|
| ICT | Inner Circle Trader — FVG · 유동성 · 구조 전환 등을 말하는 트레이딩 교육 계열. 이 프로젝트의 출발점 |
| FVG | Fair Value Gap — 3봉 사이 가격 공백(임밸런스). 되돌아와 메울 때 진입하는 셋업 |
| CHoCH / BOS | Change of Character(추세 전환) / Break of Structure(추세 지속) — 스윙 고저점 돌파로 정의 |
| CISD | Change in State of Delivery — 연속 캔들의 첫 시가를 넘는 순간을 전환 확인으로 쓰는 트리거 |
| 스윙 · 프랙탈 | 좌우 k 봉(lookback)보다 높은 고점 / 낮은 저점 |
| VP · POC | Volume Profile(가격대별 거래량) · Point of Control(최대 거래량 가격) |
| 청산 이벤트 · 캐스케이드 | 강제청산이 연쇄로 터지며 가격이 한쪽으로 쏠리는 구간(거래량 · 봉 크기로 추정) |
| painR3 | 가상 트레이더들의 미실현손실(R 단위, 3R 상한) 합의 롱 / 숏 불균형 — 문서 45 ~ 54 |
| R · 1R | 진입가 ~ 손절가 거리. 성과를 그 배수로 잰다 |
| 총R · 순R · 수수료R | 비용 전 · 비용 후 · 비용을 1R 로 나눈 값 |
| bps | 0.01%. 6bps = 0.06% |
| 테이커 · 메이커 | 시장가(즉시 체결, 수수료 높음) · 지정가(호가에 걸어둠, 수수료 낮음) |
| 펀딩 | 무기한 선물의 8시간마다 정산. 양수면 롱이 숏에게 낸다 |
| IS · OOS · 홀드아웃 | 표본 안(규칙을 만든 구간) · 표본 밖(한 번만 여는 확인 구간) · 마지막 12개월 등 남겨둔 구간 |
| 봉인 창 | 2026-07-05 00:05 ~ 09-24. 규칙 확정 뒤 사용자 확인을 받고 한 번만 여는 구간 |
| 사전등록 | 실행 전에 규칙 · 판정 기준을 문서로 고정하는 것 |
| 무작위 · 치환 · 거울 · 위약 대조군 | [연구 규약 3절](METHODOLOGY.md#3-대조군--그-숫자는-무엇과-비교해-큰가) |
| t 값 · 월 클러스터 t | 평균 ÷ 표준오차. 같은 달 거래를 한 묶음으로 봐 상관을 반영한 t |
| 다중검정 | 여러 셀을 보면 우연히 큰 t 가 나오는 문제 |
| TSMOM (시계열 추세) | 각 자산의 **자기** 과거 수익 부호를 따라가는 전략. 코인끼리 순위를 매기는 횡단면 모멘텀과 다르다 |
| lookback | 추세를 재는 과거 길이(여기선 28일) |
| 역변동성(S1) | 코인 비중을 변동성에 반비례하게(위험 균등) |
| G (총노출) | Σ\|코인 명목\| ÷ 자산. G 0.75 = 자산의 75% 만큼 명목 |
| B · 실효 G | 명목 계산에 쓰는 기준 자산(매월 갱신) · 실제 총노출 = G × B ÷ 지금 자산 |
| 교차 증거금 · MMR | 계좌 전체 자산을 증거금으로 공유 · 유지증거금률(여기선 2% 가정) |
| 샤프 | 연 수익 ÷ 연 변동성 (무위험 이자 0) |
| CAGR · 연복리 | 연평균 복리 성장률 |
| MDD · 최대낙폭 | 고점 대비 가장 깊은 하락(여기선 장중 5분봉 저점 포함) |
| 블록 부트스트랩 | 과거 수익을 블록(4주)째 뽑아 이어 붙여 가상의 경로를 만드는 방법 |
| 분산비 | q 주 합의 분산 ÷ (q × 주간 분산). 1 보다 작으면 되돌림(평균 회귀) |
| 켈리 · 절반 켈리 | 장기 복리를 최대로 하는 베팅 크기 · 그 절반(복리의 약 3/4 를 변동성 절반으로) |
| 변동성 끌림 | 연복리 ≈ 산술 수익 − 분산 ÷ 2. G 를 키우면 G² 로 커진다 |
